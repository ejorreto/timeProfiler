# timeProfiler — Agent Quick Reference

C library for embedded time profiling. CMake build with environment-specific compilation.

## Build

```bash
mkdir -p build && cd build
cmake ..               # default = POSIX (builds library + example_posix)
cmake .. -DENV=TEST    # unit-test environment (library + tests + coverage)
cmake .. -DENV=RTEMS   # RTEMS target
cmake .. -DENV=FREERTOS # FreeRTOS target
make
```

- Output dirs: `build/ar`, `build/lib`, `build/bin`
- `compile_commands.json` is generated automatically.

## Test & Coverage

Requires `gcovr` installed.

```bash
cd build
cmake .. -DENV=TEST
make unittest
```

## Documentation

```bash
cd build
cmake ..
make docs               # requires Doxygen installed
```

- Generated HTML lands in `doc/html/`.
- `README.md` is used as the Doxygen main page.

## Docker Build

A non-interactive Docker script is available for CI or one-shot builds:

```bash
./docker_build.sh
```

This runs the POSIX build, unit tests, and Doxygen generation inside the `ejorreto/c_dev_2026` container.

- `make unittest` is a **custom target**; it cleans `.gcda`, runs `ctest -V`, and then generates coverage reports via `gcovr`.
- Do **not** run `make test` or `ctest` directly if you want coverage; use `make unittest`.
- Reports land in `reports/`: `coverage.html`, `coverage_report.txt`, `sonar_coverage.xml`, `ctest-results.xml`.

## Architecture

- `library/` — Core library (`timeProfiler.c`, `timeProfiler_clock_*.c`, headers in `include/`)
- `examples/` — `example_posix.c` and `example_statistics_printf.c` (reference statistics printer)
- `test/` — Unity + CMock tests (`test_timeProfiler.c`)
- `external/` — Vendored Unity and CMock

### Key interface points

- `tProfReadClock(void)` — platform-specific clock; implementations live in `library/src/timeProfiler_clock_*.c`.
- `tProfGetStatistics` — **function pointer** the application must set (e.g., to `tProfPrintfStatistics`) before auto-statistics modes will output anything.
- `TPROF_INIT(name, n, mode)` — macro that declares a local increment array and initializes the struct.

### Mocking

Tests mock `tProfReadClock` via CMock. If you change `timeProfiler_clock.h`, regenerate the mocks:

```bash
# From CMock docs / typical invocation
ruby <cmock_path>/lib/cmock.rb -o test/cmock_config.yml library/include/timeProfiler_clock.h
```

Mock files are in `test/mocks/`.

## CI / Quality

- GitHub Actions runs SonarCloud analysis with `build-wrapper` + `sonar-scanner`.
- Sonar config: `sonar-project.properties`
- Coverage XML (`reports/sonar_coverage.xml`) is consumed by SonarCloud.

## Code Style

- `-Wall -Werror` is enforced in all CMake configurations.
- Files use GNU LGPL v3 license headers.
- Keep generated mocks and coverage reports out of manual edits; mocks are marked `AUTOGENERATED FILE. DO NOT EDIT.`

## Common Pitfalls

- Forgetting `-DENV=TEST` before running `make unittest` — the `unittest` target only exists in TEST mode.
- Changing the clock header without regenerating CMock mocks — tests will fail to compile.
- Running `tProfCalculateStatistics` on a running or empty profiler sets `status = TPROF_ERROR`.
